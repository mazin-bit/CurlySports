# Homepage sport avatars

Add your three avatar images here with these exact names:

- **soccer.png** – Football/Soccer avatar (boy with soccer kit and ball)
- **cricket.png** – Cricket avatar (boy with bat and pads)
- **f1.png** – Formula 1 avatar (boy in F1 car)

The homepage will show these in the sport cards for each enabled sport. If a file is missing, the card will show an icon instead.
